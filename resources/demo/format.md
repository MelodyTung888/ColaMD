## 公式（v1.7，来自社区 PR #14）

按 **⌘⇧E** 打开插入公式弹窗，点击公式可以编辑。KaTeX 渲染：

$$
E = mc^2
$$

行内公式 $a^2 + b^2 = c^2$ 也可以。

## Mermaid 图表（v1.7.4）

在代码块首行写上 `mermaid`，ColaMD 会直接渲染图表：

```mermaid
flowchart LR
  Agent[AI Agent] --> File[Markdown 文件]
  File --> ColaMD[ColaMD 实时同步]
```

## 搜索

按 **⌘F** 搜索当前文档，匹配项会高亮。
