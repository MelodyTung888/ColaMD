# ColaMD Melody Changelog

欢迎来到 ColaMD 的**可玩 changelog**。左侧面板列出的就是本目录的文件——点击切换，每个文件演示一组功能。这是演示副本，玩坏了随时可以从仓库恢复。

---

## v1.9.0 · Melody 独立版（开发中，尚未发布）

- **macOS 独立身份**：应用名改为 ColaMD Melody，使用独立 Bundle ID、GitHub Release 与更新源，只构建 Apple Silicon（arm64）版本
- **更易拖动的滚动条**：加宽编辑器右侧纵向滚动条的鼠标命中区域
- **层级文件树**：文件夹在原位置展开/收起，可连续查看多层目录，不再进入后替换整张列表
- **轻量加载**：每个窗口只有一个会话级树根，只读取和监听根目录及已展开分支，不建立持久化 Vault，也不全量扫描磁盘
- **访达式右键操作**：新建 Markdown、新建文件夹、创建文件副本，以及将文件或文件夹移到废纸篓
- **目标文件导出**：右击 Markdown 文件即可导出 PDF 或 HTML；导出其他文件不会切换或污染当前文档

展开左侧的 `file-tree-demo`，可以直接体验多层文件夹的原地展开方式。右键菜单会依据空白处、文件夹或 Markdown 文件显示相应操作。

## v1.8.2 · 内置主题

- 新增 12 个内置主题，包含 6 个浅色主题与 6 个深色主题

## v1.8.1 · 启动体验与 macOS 图标视觉刷新

- **macOS 应用图标**：中央 Cola 红色主体改为黄金分割比例的正方形
- **图标层次**：统一透明圆角、阴影、渐变和多尺寸 ICNS 资源
- **视觉收敛**：保留单一波浪线，移除多余装饰弧线
- **稳定性修复**：移除 Mermaid 图表渲染，代码块恢复为原生编辑体验
- **无权限启动**：首次打开默认展示内置示例，不再扫描用户的「文稿」目录
- **双语语法文档**：Help 根据系统语言自动显示对应版本

## v1.8.0 · 图片路径保存修复与编辑体验完善

这一版继续收敛社区反馈，并修复本地图片路径在显示和保存之间的边界问题：

- **图片路径可移植保存**：编辑器渲染时使用 `file://` URL，保存 Markdown 时恢复为相对于文档的路径
- **HTML 图片路径同步修复**：原生 `<img src="...">` 也不会把绝对 `file://` 路径写回源文件
- **社区 Issue 收尾**：代码块复制、HTML 图片、Windows 路径、VS Code 未保存内容和格式编辑均已完成

## v1.7.4 · 社区反馈与 Markdown 工作流

昨天发布 v1.7.3 后，我们收到了社区的反馈。这一版带来：

- **源码模式**：在所见即所得和原始 Markdown 之间快速切换
- **文件面板完善**：支持轻量目录浏览；没有打开文件时默认展示「文稿」目录
- **HTML 导出**：将当前文档导出为独立 HTML 文件
- **Windows 图片路径**：修复 Windows 本地图片显示
- **VS Code 集成 MVP**：从 VS Code 将当前 Markdown 文件打开到 ColaMD

## 模拟 Agent

打开终端，对当前目录做点改动，窗口会实时响应：

```bash
echo '- [ ] 这是 Agent 刚写入的任务' >> tasks.md
echo '# 全新文件' > new.md
```

第二行会**实时**出现在左侧面板里——文件面板和内容一起动。

Markdown 语法请使用 Help 中的主入口，内容会根据系统语言自动选择。
